# Glossary

도메인 용어. 새 용어는 여기 먼저 추가한다.

| 용어 | 설명 |
|------|------|
| DRPC | 이 저장소의 분산 RPC 스택 브랜드명 |
| RPC Attribute | 원격 호출 계약을 선언하는 Attribute |
| Shared | Client/Server가 공유하는 계약·직렬화 연동 |
| CodeGenerator | RPC·계약 코드를 생성하는 Roslyn 소스 생성기 |

## 공통 (DS 스택)

| 용어 | 설명 |
|------|------|
| netstandard2.1 | Unity 및 다중 .NET 런타임 호환 타깃 |
| NuGet | 패키지 배포 단위 |
| Sandbox / Examples | 샘플·데모 프로젝트 |
